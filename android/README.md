# Android — Доходы–расходы

**Версия:** 1.2.0 (`versionCode` 3)

Клиент к GAS Web App: **Главная** (ввод), **Финансы**, **Заметки**. Категории — в **Настройках**.

Руководство: [../GUIDE.md](../GUIDE.md). Откат версии: [../VERSION.md](../VERSION.md).

## Сборка

JDK **17 или 21** (не 25 из Android Studio):

```bash
cd android && ./build-apk.sh
```

APK: `app/build/outputs/apk/debug/app-debug.apk` — в «О приложении» должно быть **1.2.0**.

## Настройка

1. Таблица: **Токен для Android…**
2. Deploy: **Me** + **Anyone**, URL `…/exec`
3. ⋮ → **Настройки** → URL + token → **Проверить связь**

## Использование (1.2.0)

- **Главная** — два блока: расходы/доходы и заметка (текст / 🎤)
- **Финансы** — баланс, фильтр, список транзакций
- **Заметки** — компактный список; чекбокс и дата/время в строке
- **Настройки** — подключение и категории

Данные кэшируются после `bootstrap`; запись на сервер — в фоне.  
Ключ Gemini только на сервере.
