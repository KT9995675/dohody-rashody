# Android — Доходы–расходы

**Версия:** 1.1.0 (`versionCode` 2)

Клиент к GAS Web App: список, быстрый ввод заметки (текст / голос), CRUD записей. Категории — в **Настройках**.

Руководство: [../GUIDE.md](../GUIDE.md). Откат версии: [../VERSION.md](../VERSION.md).

## Сборка

JDK **17 или 21** (не 25 из Android Studio):

```bash
cd android && ./build-apk.sh
```

APK: `app/build/outputs/apk/debug/app-debug.apk` — в «О приложении» должно быть **1.1.0**.

## Настройка

1. Таблица: **Токен для Android…**
2. Deploy: **Me** + **Anyone**, URL `…/exec`
3. ⋮ → **Настройки** → URL + token → **Проверить связь**

## Использование (1.1.0)

- **Список** — баланс, фильтр (в т.ч. период), тап по записи → правка
- **Composer внизу** — текст + ➤ или 🎤 (тап = старт/стоп записи)
- **Настройки** — подключение и категории

Ключ Gemini только на сервере.
