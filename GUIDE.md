# Руководство пользователя — Доходы–расходы

Личный учёт доходов и расходов в Google Таблице. Два клиента: **веб** (компьютер) и **Android** (телефон, быстрый ввод).

Подробности для разработчика: [SPEC.md](SPEC.md). Версии и откат: [VERSION.md](VERSION.md).

---

## 1. Первый запуск (один раз)

### 1.1. Таблица и скрипт

1. Откройте [таблицу](https://docs.google.com/spreadsheets/d/1LMePvTBpQzood5DjqNJmvvHagveiN8tR4xYkxCRgpII/edit) и [скрипт](https://script.google.com/d/1jOK0doAHaUMMsw6iKLRiJCmDZ-T9JUnPy_8Svf_P0GvCdrfpZCx6KJ17/edit) (если уже привязаны к проекту — пропустите).
2. В таблице: меню **Доходы–расходы → Первичная настройка (setup)**.
3. **Настроить Gemini…** — вставьте API-ключ из [Google AI Studio](https://aistudio.google.com/apikey). Модель по умолчанию: `gemini-3.0-flash` (для скорости thinking сведён к минимуму).
4. **Проверить Gemini** — тестовый разбор фразы.
5. **Deploy → Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone** (нужно для Android; веб-страница всё равно только для владельца)
   - Скопируйте URL вида `https://script.google.com/macros/s/…/exec` (не `/dev`).

### 1.2. Android

1. Установите APK (сборка: [android/README.md](android/README.md)).
2. ⋮ → **Настройки**:
   - URL веб-приложения (`…/exec`)
   - **Токен Android** — из меню таблицы **Токен для Android…**
   - **Сохранить** → **Проверить связь** → должно быть `OK. Gemini: true`.

## 2. Android (основной сценарий на телефоне)

**Версия 1.2.0** — три экрана в нижнем меню.

### Навигация

| Экран | Назначение |
|-------|------------|
| **Главная** | Ввод без списков: блок «Расходы/доходы» и блок «Заметка» (текст + 🎤) |
| **Финансы** | Баланс, фильтр дат, список транзакций |
| **Заметки** | Список напоминаний; чекбокс «Показывать завершённые» |

### Добавить расход/доход

1. На **Главной** введите фразу или нажмите 🎤.
2. Экран **Подтверждение** — проверьте тип, сумму, категорию.
3. **Записать** → запись в листе `Transactions`.

### Добавить заметку

1. На **Главной** во втором блоке введите текст или 🎤, например: `завтра в 15:00 купить молоко`.
2. Экран подтверждения: **текст**, **дата**, **время** (может быть пустым).
3. **Записать** → лист `Notes` в таблице.

Завершённые заметки скрыты; включите «Показывать завершённые» на экране **Заметки**.  
В списке каждая заметка — **в одну строку**: чекбокс · текст · дата · время (тап по тексту — правка).

### Настройки

- **Подключение:** URL и token.
- **Категории:** CRUD для расходов (в списке — одна строка: имя · переименовать · удалить).

## 3. Веб (компьютер)

Откройте URL веб-приложения (`…/exec`) под аккаунтом **владельца** таблицы.

Вкладки: **Главная** · **Финансы** · **Заметки** · **Категории**.

- Голос в iframe GAS недоступен — только текст на **Главной**.
- Списки заметок и категорий — компактно в одну строку на элемент.
- Категории расходов — отдельная вкладка (не под списком операций).
- Android и веб работают с **одной таблицей** (`Transactions`, `Categories`, `Notes`).

## 4. Правила учёта

| Правило | Пояснение |
|---------|-----------|
| Валюта | Рубли |
| Баланс | Все доходы − все расходы (не зависит от фильтра списка) |
| Категории | Только у **расходов** |
| Подтверждение | Любая новая запись — только после вашего «Записать» |
| Дата | При создании — сегодня; на экране записи можно изменить |

## 5. Если что-то не работает

| Симптом | Что проверить |
|---------|----------------|
| «Неверный token» | Токен из меню таблицы; без лишних пробелов; тот же деплой `…/exec` |
| HTML / HTTP 405 | Деплой **Anyone**; URL **/exec**; переустановить свежий APK |
| HTTP 404 (иногда само проходит) | Одноразовый редирект Google; приложение повторяет запрос. Если часто: **Deploy → Manage deployments → Edit → New version** после `clasp push` |
| Разбор голоса/текста очень долгий | Модель должна быть Gemini 3 с минимальным thinking; после обновления скрипта — **Новая версия** деплоя; короткие фразы |
| Gemini не отвечает | Ключ в Script Properties; **Проверить Gemini** в меню; для AI Studio из РФ может понадобиться VPN при настройке |
| Список пустой | Фильтр «Всё» или расширить период |
| Сборка APK падает | JDK **21**, не 25 из Android Studio — см. [android/README.md](android/README.md) |

---

## 6. Где что хранится

| Данные | Где |
|--------|-----|
| Записи, категории, заметки | Листы `Transactions`, `Categories`, `Notes` в Google Таблице |
| Ключ Gemini | Script Properties (`GEMINI_API_KEY`) |
| Токен Android | Script Properties (`MOBILE_API_TOKEN`) + поле в настройках APK |
| URL приложения | Настройки APK |

Ключ Gemini **не** вшит в APK.
